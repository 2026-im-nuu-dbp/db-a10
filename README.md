## 作業說明
自行設計題目，但須具備下列功能: 
1. 三個資料表，一個用來存放註冊資料，一個用來存放 log 資料，一個用來存放圖文備忘資料。
   資料表命名分別為 dbusers, dblog 及 dememo 。完成後請將資料表匯出，填入到資料夾中。
2. 具備註冊功能，註冊資料包含
   a. 帳號
   b. 暱稱
   c. 密碼
   d. 性別
   e. 興趣
   ...
3. 具備登入功能，需註冊後才能登入
4. 任何人登入時，紀錄登入者帳號，日期時間以及是否登入成功
5. 登入後可以新增圖文備忘，至少包含
   a. 新增者(使用者id)
   b. 多行文字
   c. 上傳一張圖片，進行縮圖後存放
   d. ...
6. 圖文備忘功能具備 新增、刪除、修改、列出
7. 登入資料可以被瀏覽

## 自行設計的內容說明(同學自填)
我們這個系統主要是在做一個圖文備忘錄管理系統。使用者一開始需要先註冊帳號，註冊時要填帳號、密碼跟電子郵件。送出之後，系統會寄一封啟用信到使用者的信箱，裡面會有一個啟用連結。使用者要點擊那個連結，帳號才會開通，這樣可以避免亂註冊或惡意登入。

帳號開通之後才可以登入系統。登入成功後，使用者可以開始使用備忘錄功能，包括新增、修改、刪除還有查看自己的備忘資料。備忘內容可以輸入多行文字，還可以上傳圖片，系統會同時存原圖跟縮圖，讓之後瀏覽比較快。

另外系統也會記錄每一次登入的狀況，像是登入時間、帳號，以及登入成功或失敗，方便之後做查詢或安全管理。

在通知系統的部分，我們有做一個管理員功能。管理員可以輸入信件的主旨跟內容，系統會自動寄送給所有已經註冊並且完成啟用的使用者，而且信件裡也可以附上圖片，用來做公告或通知。

整體來說，這個系統重點在於功能完整但操作簡單，包含帳號驗證、備忘錄管理以及通知寄信，算是一個基本但實用的會員系統應用。
